# ЛР3 / Дроби

## Собрать и запустить

`. ./run.sh` или `source ./run.sh`

*все флаги при запуске run.sh передаются как флаги при запуске исполняемого файла*

## Команды сборки
* `cmake -B .build`
* `make -C .build`


## Команды запуска
Режим демонстрации:
`./lab_3`

Интерактивный режим:
`./lab_3 -i`
