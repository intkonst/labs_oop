# ЛР2 / Классы

Вариант: автомобиль


## Команды сборки
* `cmake -B .build`
* `make -C .build`


## Команды запуска
Режим демонстрации:
`./lab_2`

Интерактивный режим:
`./lab_2 -i`



*p.s. Входные файлы с примерами в директории `/db` можно редактировать прям там, они автоматически скопируются в `/.bin` при повторной сборке.*
