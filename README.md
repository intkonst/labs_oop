# ЛР2 / Переход от стркутр к классам 

Вариант: автомобиль


## Комманды сборки:
* `cmake -B .build`
* `make -C .build`

***Предварительно создать папку `.bin`, в ней будут лежать собранные исполняемые файлы! Затем скопировать текстовые файлы из db в `.bin`.***


## Команды запуска
Режим демонстрации:
`./lab_2`

Интерактивный режим:
`./lab_2 -i`
